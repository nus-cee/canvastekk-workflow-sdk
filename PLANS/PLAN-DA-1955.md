## Assumptions (ticket gaps → locked decisions)

1. **Diff breaking rule** mirrors the engine's `detect_breaking_changes` + Activepieces checklist: **removed output property = breaking; newly-required input = breaking**. Everything else (new optional input, new output, un-required input, metadata changes) = non-breaking, reported.
2. **Same-version + any diff → CLI error** (exit 1): aligns with the engine's publish-once immutability (DA-1952); breaking changes additionally require a MAJOR bump to exit clean.
3. **Compat fields flow through `constraints`** (engine `RegisterNodeRequest.constraints` is a free-form dict — no engine change needed this ticket). Reserved keys `minimum_sdk_version` / `maximum_sdk_version`; explicit `constraints` arg merges over manifest-derived keys (caller wins). Engine consumption (drift `engine_compatible`) = follow-up engine pin-bump.
4. **Typed errors = enriched `RegistrationError`** (new attrs `error_code`, `guidance`) rather than an exception hierarchy — one class, actionable messages, zero breakage for existing `except RegistrationError` callers. Mappings only for codes reachable from the register endpoint: `node_version_immutable` (409), `resource_conflict`-style older-semver 409, `node_retired` (410), 400/422 validation.
5. **Uploader retry**: 3 attempts total, retry ONLY on `httpx.TransportError` (network) or HTTP ≥500; backoff 0.5s·2^(n-1); file reopened per attempt (stream consumed). 4xx never retried (S3 presigned 403 = deterministic).
6. **`auth` param on `create_node_app`**: `NodeAuth | "api-key" | "admin" | None`; string shorthands construct NodeAuth level; merges with explicit `dependencies` (auth appended). Default None = current behavior + existing startup warning.
7. **P2 fields** (`docs_url`, `changelog_url`) included — trivial optional strings serving DA-1937 preview; same drop-when-none treatment.
8. **TS parity**: definition/registry/uploads/diff all mirrored; no TS CLI (TS SDK is a library; CLI is Python-only per current shape).
9. Version files touched manually (`__init__.py:171`, `python/pyproject.toml:3`, `typescript/package.json` + lockfile refresh); CHANGELOG is generated by git-cliff in release.yml on main — no manual CHANGELOG edit.
10. Engine-side pin bump to 0.23.0 is **out of scope** (follow-up chore in engine repo, 7-file checklist `LEARNINGS/conventions/sdk-upgrade-checklist.md`).

## Risks & Mitigation

- **Retry double-upload on ambiguous timeout**: S3 PUT is idempotent for same content (same presigned URL, fixed Content-Length); worst case = redundant bytes. Accepted.
- **Constraints key collision**: reserved-key document + caller-wins merge rule (Assumption 3).
- **Error-envelope drift (engine ↔ SDK)**: mapping is additive/optional — unknown codes fall back to today's message; contract pinned by tests on both sides.
- **TS/python diff classification drift**: mirrored test matrices; future divergence caught by PARITY review discipline.
- **auth param string shorthand set**: kept minimal (`"api-key"`, `"admin"`); factory names verified at implementation time.
